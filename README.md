# Personal Portfolio Website

A responsive, PWA-compliant personal portfolio website showcasing projects, blog posts, and a contact form, built with modular HTML, CSS, and JavaScript.

## Features
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
- **Modular Architecture:** Clean separation of concerns with modular JavaScript components and CSS styling.
- **Progressive Web App (PWA):** Includes a Web App Manifest and a Service Worker for offline support and installability.
- **Dynamic Projects Section:** Projects are rendered dynamically via modular JavaScript.
- **Interactive Contact Form:** Fully styled, responsive form with user feedback states.

## Tech Stack
- **HTML5** (Semantic elements)
- **CSS3** (Custom variables, Flexbox, Grid)
- **JavaScript (ES6+ Modules)**
- **GitHub Pages** (Deployment & Hosting)
